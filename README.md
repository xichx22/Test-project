# tsignal — 단타 신호의 근거를 만드는 파이프라인

"어떤 신호에 진입하고 어떤 신호에 청산할 수 있는가"를 **감이 아니라 통계로** 답하기 위한 프로젝트.

지표를 많이 그리는 게 목적이 아니다. 지표 61종 → 신호 39개 → 상태필터 15개로
만든 조합 2,440개를 같은 잣대로 줄 세우고, **살아남는 것만 남기는 것**이 목적이다.
코스피·코스닥 시총 상위 199종목 5년치로 검증한다.

```
데이터소스 ─▶ 지표(61) ─▶ 트리거(39) ─▶ 조합(2,440) ─▶ 검증 ─▶ 리포트
 네이버/CSV    envelope    진입 30        × 상태필터 15   날짜 군집 보정  "근거표"
 /토스/합성    DEMA, %R…   청산 9         (같은 축 제외)  12폴드 워크포워드
```

## 설계 원칙

이 네 가지가 없으면 백테스트 결과는 전부 자기기만이다.

### 1. 미래참조 금지 — 기계로 검사한다

신호는 t봉 종가 확정 후 계산하고, 체결은 **t+1봉 시가**로 잡는다.
`tests/test_no_lookahead.py` 가 두 방향으로 강제한다.

- **동작 검사**: 데이터를 t봉에서 잘라 계산한 값 == 전체 데이터로 계산한 t봉 값
- **정적 검사**: 지표/신호 소스에 음수 `shift` 가 있으면 실패 (주석·문자열은 토크나이저로 제외)

실제로 미래참조 지표를 하나 주입해 두 검사가 모두 잡는 것을 확인했다.

### 2. 비용은 전략의 일부가 아니라 전략 그 자체다

기본값 왕복 **28bp** (수수료 1.5bp×2 + 거래세 15bp + 슬리피지 5bp×2).
5분봉 단타의 회당 기대수익은 대개 10~30bp 규모라, 비용을 빼는 순간 대부분의
"잘 되는 신호"가 사라진다. 그래서 비용 차감 후 숫자만 리포트에 싣는다.

### 3. 신호 39개를 동시에 시험하면 t=2 는 문턱이 아니다

엣지가 전혀 없어도 39개 중 두어 개는 t>2 가 나온다. Šidák 보정으로
문턱을 **|t| ≥ 3.1~3.2** 로 올리고, 그 위에 OOS 재현까지 요구한다.

### 3-1. **원시 수익률이 아니라 초과수익을 검정한다**

실데이터를 넣고 나서 발견한 가장 중요한 함정이다.
보유기간을 늘리면 어떤 신호든 t가 커진다 — 시장이 우상향하면
"아무 때나 사서 들고 있기"의 기대값이 양수이기 때문이다.

실제 24종목·5년 일봉에서 보유 20일 기준:

| 신호 | 원시 t | 초과수익 t | 판정 |
| --- | --- | --- | --- |
| `donchian_breakout` | 6.24 | **1.35** | 기각 |
| `cmf_turn_positive` | 6.24 | **2.02** | 보류 |
| `bollinger_lower_reclaim` | 5.13 | **1.40** | 보류 |

원시 t로 판정하면 셋 다 "채택후보"다. 종목별 무조건부 평균을 뺀
**초과수익(edge)** 의 t로 보면 하나도 문턱을 못 넘는다.
그 격차가 곧 '시장이 벌어준 몫'이다.

### 3-1-b. 같은 날 100종목이 동시에 신호를 내면, 그건 관측 1개다

**이 프로젝트에서 결과를 가장 크게 바꾼 수정이다.**

한국 주식 199개는 같은 날 같이 움직인다. 시장이 빠진 날에는 수십~백 종목에서
`bollinger_lower_reclaim`이 동시에 뜬다. 이걸 독립 관측으로 세면 표준오차가
√n만큼 작아져 t가 부풀려진다. 실측 인플레이션:

| 신호 | 순진한 t | 날짜 군집 보정 t |
| --- | --- | --- |
| `bollinger_lower_reclaim` | 5.93 | **0.58** (10배) |
| `donchian_breakout` | 3.56 | **−0.79** (부호 반전) |

보정 전에는 조합 43개가 Šidák을 통과했다. 보정 후에는 **0개**다.
유효 표본은 신호 발생 횟수가 아니라 **발생 날짜 수**다 (Fama-MacBeth 방식).

### 3-2. 한 종목이 아니라 유니버스로, breadth까지

풀링 기대값이 유의해도 24종목 중 3종목이 다 벌어준 것일 수 있다.
`breadth`(종목별 초과수익이 양(+)인 비율)가 0.6 미만이면 `쏠림주의`로 따로 뺀다.

관문을 **모두** 통과해야 `채택후보`:
표본 100회 이상 → 보정된 t_edge 문턱 통과 → breadth ≥ 0.6 → IS/OOS 부호 일치.

### 4. 검증 코드가 없는 엣지를 만들어내지 않는지 검사한다

합성 랜덤워크를 넣었을 때 채택후보가 하나라도 나오면 파이프라인이 고장난 것이다.
`test_random_walk_produces_no_significant_edge` 가 이걸 회귀 테스트로 고정한다.
(실제로 합성 데이터 리포트의 결론은 "채택후보 없음"이다 — 정상이다.)

## 리포트가 답하는 것

1. **진입 신호 스크리닝** — 신호별 기대값 / 무조건부 대비 초과분(edge) / t / IS·OOS / 판정
2. **구간 안정성** — 5등분 구간마다 부호가 유지되는가 (한 구간이 다 벌어준 건 아닌가)
3. **청산 규칙 비교** — 같은 진입에 청산 규칙만 갈아끼웠을 때 순손익이 어떻게 달라지는가
4. **익절/손절 폭 근거** — MFE/MAE 분포 분위수 (%와 ATR 배수 양쪽으로)
5. **청산 사유 분해** — 손절/익절/청산신호/시간/당일청산 각각의 기여

## 토스 API 실측 상태

토스증권은 **공개 문서화된 REST API가 없다.** 내부 엔드포인트를 직접 확인한 결과:

| 엔드포인트 | 상태 |
| --- | --- |
| `GET /api/v2/stock-infos/{A코드}` | ✅ 익명 호출 동작 (종목 메타) |
| `GET /api/v2/stock-prices/{A코드}` | ✅ 익명 호출 동작 (현재가 스냅샷) |
| `GET /api/v1/c-chart/kr-stock/{A코드}/{period}` | ⚠️ 라우트는 존재하나 400 (과거 캔들) |

캔들 경로는 존재하지 않는 경로(404)와 달리 **400**을 준다 — 라우트는 맞고
인증/필수 파라미터가 빠진 상태다. period 후보와 파라미터 후보를 조합 검증했으나
전부 400이었고, 브라우저 세션 헤더가 필요할 가능성이 높다.

그래서 어댑터는 (1) 검증된 엔드포인트를 제공하고, (2) 헤더/쿠키 주입 구멍을 열어두고,
(3) 파라미터 재탐색 도구를 함께 둔다:

브라우저에서 차트 요청을 **우클릭 → Copy → Copy as cURL** 해서 파일로 저장한 뒤:

```bash
.venv/bin/python -m tsignal probe-toss --curl 저장한파일.txt
```

경로·파라미터·헤더·쿠키를 분해하고, 요청을 재현해 200을 확인하고,
파라미터를 하나씩 빼보며 필수 항목만 추린 뒤, 응답을 캔들로 파싱해 본다.
확인되면 `toss.session.json` 으로 저장되어 이후 수집에 그대로 쓰인다.

> SPA 번들에서 파라미터를 직접 찾아보려 했으나 실패했다 — 청크 39개(1.3MB)에
> `c-chart` 관련 코드가 없고, 이 IP 에는 내용 없는 껍데기 페이지만 내려온다.
> 브라우저 없이는 확정할 수 없다.

자세한 내용은 [`docs/toss-api.md`](docs/toss-api.md).

> 비공식 엔드포인트다. 서비스 약관을 확인하고 본인 책임으로 사용하되,
> 호출 간격(`min_interval_sec`)을 지킬 것. 상용 배포나 대량 수집이 목적이라면
> 한국투자증권 Open API 같은 **공식 채널**을 권한다 — 어댑터만 하나 더 쓰면 된다.

### 3-3. 조합 탐색은 과최적화 기계다

트리거 27개 × 상태필터 조합 = 2,199개(중복 제거 후)를 훑으면, 엣지가 전혀 없어도
t>3짜리가 수십 개 나온다. 그래서 **IS에서 고르고 OOS로 채점하는** 프로토콜을 강제한다.
IS 상위 20개 중 OOS 생존 개수를 우연 기대치(약 3.2개)와 이항검정으로 비교한다.

탐색 공간도 미리 줄인다:

- 같은 축의 필터끼리는 결합하지 않는다 (`추세상승 AND 추세하락` 같은 공허한 조합 제거)
- **봉 집합이 동일한 조합은 하나로 합친다.** `not_overbought`(RSI<70)는 90% 구간에서
  참이라 `X + not_overbought`가 `X` 단독과 글자 그대로 같아진다. 실측 3,150개 중
  **52%가 중복**이었고, 이걸 남기면 문턱도 p값도 모두 왜곡된다

### 3-3-b. 기준선을 창 안 평균으로 잡으면 없는 엣지가 생긴다

**앞선 결론을 통째로 뒤집은 버그다.**

초과수익 = 수익률 − 기준선인데, 기준선을 "그 종목의 창 안 평균"으로 잡으면
**인공적인 평균회귀**가 생긴다. `trend_down`(종가<60EMA)처럼 "자기 평균 아래"를
고르는 조건은 정의상 평균 밑을 고르고, 그 뒤에는 평균으로 되돌아온다 —
엣지가 전혀 없어도.

엣지가 0인 랜덤워크로 확인:

| 창 길이 | `trend_down` lift 가 양수인 비율 | 중앙 lift |
| --- | --- | --- |
| 60일 | 78% | +0.117% |
| 120일 | 67% | +0.082% |
| 250일 | 75% | +0.086% |
| 500일 | 50% | +0.008% |

창이 짧을수록 인공물이 커진다. 워크포워드의 3개월 검증창이 정확히 이 구간이었다.

**기준선은 "같은 날 전 종목 평균"(횡단면)이어야 한다.** 바꾸고 나니
`trend_down` 은 12/12 → **4/12**, lift 음수, p=0.39 가 됐다.

### 3-3-c. 20일 수익률을 매일 계산하면 관측이 19/20 겹친다

날짜 군집 보정은 **같은 날 안의** 상관만 잡는다. 날짜 **사이의** 겹침은 그대로다.
겹치지 않게 표본을 뽑아 다시 재면 t 가 √h 배쯤 내려간다.

| 팩터 | 겹침 t | 비겹침 t |
| --- | --- | --- |
| `atrp_14` | 13.50 | 3.03 |
| `ret_120` | 8.62 | 1.95 |
| `ema60_gap` | 6.12 | 1.36 |

### 3-3-d. 횡단면 평균을 빼도 베타는 남는다

고변동성 종목은 시장이 오를 때 평균보다 더 오른다. 상승장 표본에서는 그것만으로
스프레드가 생긴다. 롱숏 스프레드를 시장수익률에 회귀해 알파를 분리하면:

`atrp_14` 는 스프레드 4.12%가 시장으로 56% 설명되고, 남은 **알파의 t 는 1.20** 이다.

### 3-4. 분할은 한 번이 아니라 열두 번

IS/OOS를 한 번만 자르면 결론이 "어느 날짜에 잘랐는가"에 걸린다. 학습 24개월 /
검증 3개월 창을 3개월씩 밀며 **12폴드**를 돌린다.

폴드 수는 검정력과 직결된다. 필터 15개를 동시에 검정하면 보정된 p 문턱은 0.0034인데,
폴드 6개짜리 부호검정의 **최소 가능 p가 0.031**이라 어떤 결과도 원리적으로 통과할 수
없다. 12폴드면 최소 p가 0.0005까지 내려가 비로소 판정이 가능해진다.

집계 단위도 폴드다. 한 폴드 안의 조합 20개는 표본이 겹쳐 독립이 아니다 —
실제로 한 폴드에서 1/20, 다른 폴드에서 19/20이 사는 식으로 함께 움직인다.

## 차트 매매법 11종 — 유명한 것 7, 덜 알려진 것 4

### 먼저: 검출기 6개 중 5개가 자기 교과서 모양을 못 잡았다

백테스트를 돌리기 전에 합성 데이터로 확인했더니 새로 만든 6개 중 **5개가
자기 정석 모양에서 안 잡혔다.** 그대로 돌렸으면 "이 패턴은 효과 없음"이라는
결론이 나왔을 텐데, 실제로는 검출기가 고장난 것이었다.

가장 컸던 실수는 **추세선을 그리는 방식**이다. 쐐기의 상단선·하단선을
모든 봉에 최소제곱으로 회귀하면 지그재그의 **한가운데**를 지나간다.
그러면 두 선이 거의 붙어서, 실제로 수렴하는 쐐기도 폭 비율이 0.913 으로
나온다(수축 판정 기준은 0.4). 차트에서 사람이 그리듯 구간을 나눠
**봉우리끼리 · 골끼리** 이어야 포락선이 된다. 고친 뒤 0.132.

세 관문을 전부 통과한 것만 백테스트에 넣었다 — (1) 교과서 모양에서 잡힌다,
(2) 비슷하지만 다른 모양은 기각한다(V자·상승쐐기·조정이 깊어지는 형태 등),
(3) 랜덤워크에서 드물다. 회귀 테스트로 고정돼 있다.

- 구간 4개면 부호검정의 **최소 가능 p 가 0.125** 다. 전승해도 0.05 를 못 넘긴다.

필요한 것은 더 긴 기간이거나 다른 시장이다. 같은 데이터를 더 들여다봐서
해결될 문제가 아니다.

### VCP 는 판정 자체를 못 했다

10년 368종목에서 **24회**밖에 안 나왔다. 미너비니 기준을 코드로 옮기면서
조정 깊이 단조감소 + 거래량 고갈 + 돌파 거래량을 전부 걸었더니 너무 좁아졌다.
"효과가 없다"가 아니라 **"쟀다고 말할 수 없다"** 가 정확하다.
기준을 느슨하게 하면 표본은 늘지만 그건 다른 규칙을 재는 것이 된다.

## 시총 상위 N 리밸런싱 — 예측이 없는데도 진다

"시가총액 상위 20종목을 들고 순위가 바뀌면 갈아탄다." 예측이 없는 규칙이라
지금까지 무너진 것들과 성격이 다르다. 그래서 따로 쟀다.
(2026년은 반도체 특이장이라 제외 — 2017-05 ~ 2025-12, 8.6년)

과거 시총은 **오늘 상장주식수 × 그날 수정주가**로 복원했다. 액면분할은
수정주가와 현재 주식수가 상쇄해 정확하고, 오차는 유상증자·소각·합병에서만 생긴다.

|---|---:|---:|---:|---:|
| **[벤치] 유니버스 368종목 동일가중 보유** | **18.90%** | −44.4% | — | — |
| **[벤치] KODEX 200** | **10.54%** | −38.1% | — | — |
| 상위10 시총가중 분기 | 9.58% | −41.2% | 0.512 | 21.03 |
| 상위20 시총가중 분기 | 8.52% | −41.2% | 0.515 | 21.05 |
| 상위50 시총가중 분기 | 7.79% | −40.8% | 0.526 | 18.97 |
| 상위20 동일가중 분기 | 5.04% | −46.0% | 0.502 | 23.39 |
| 상위20 동일가중 연1회 | 3.94% | −46.6% | 0.482 | 23.81 |

**16개 변형 전부 두 벤치마크에 졌다.** 수익만 진 게 아니라 낙폭도 더 깊다
(−41.2% vs KODEX 200 −38.1%).

비용 탓이 아니다. 분기당 명단이 1.7종목만 바뀌고 8.6년 동안 리밸런싱 34회다.
회전율이 낮아서 비용은 거의 영향이 없다.

이유는 단순하다 — **시총 상위 = 이미 많이 오른 종목**이다. 시가총액이 크다는
건 그 종목이 여기까지 올라왔다는 결과지 앞으로의 예고가 아니다. 상위 20에
집중하면 "이미 오른 것"에 집중하게 되고, 유니버스 전체를 동일가중으로
들면 자연히 덜 오른 쪽으로 기울어 그쪽이 더 나왔다 (18.90% vs 8.52%).

시총가중이 동일가중을 이긴 것(8.52% vs 5.04%)도 같은 이야기의 뒷면이다.
상위 20 안에서는 가장 큰 종목(삼성전자·SK하이닉스)이 가장 잘 갔다.

### 이 숫자를 믿으면 안 되는 이유

유니버스가 **오늘 시총 상위 368종목**이다. 2017년에 상위 20이었다가 지금은
400위 밖으로 밀려난 종목은 데이터에 아예 없다. 즉 이 백테스트는
**몰락한 대형주를 피해 간 것처럼** 계산된다 — 하필 이 전략의 핵심 위험이다.

그러니 위 표의 절대 수익률은 실제보다 높다. 그런데도 벤치마크에 졌다는 것이
결론이다. 유리한 편향을 받고도 진 것이므로, 편향을 걷어내면 더 나빠진다.

## 수익 극대화로 다시 — 규칙 5,176개를 연수익으로 줄 세웠다

"꾸준함"이 아니라 **연평균수익**을 목표로 놓고 종목 단위로 다시 훑었다.
368종목 · 11년 일봉 · 트리거 32 × 필터 16 × 보유일 4 × 동시보유 3
= **5,176개 규칙**을 전부 실제 자산가치 곡선으로 돌렸다.
`python -m tsignal swing --root data_big` 로 재현된다.

### 먼저 잡은 체결 버그 — 사기도 전의 움직임을 먹고 있었다

첫 결과는 1등이 **연 54.3%** 였다. 너무 좋아서 체결 가정부터 뜯었고, 버그가 있었다.

신호는 t봉 종가에 뜨고 체결은 t+1봉 **시가**다. 그런데 t+1봉의 수익률을
`종가/전일종가` 로 계산하고 있었다. 그러면 **전일종가 → 당일시가 갭**이
성과에 들어온다 — 내가 사기 전에 이미 벌어진 움직임이다.

실측(368종목 11년): 신호 다음날 시가 갭 평균 **+0.301%**, 전체 평균 +0.092%.
반등 신호는 갭이 크게 뜨는 자리에서 켜지므로 편향이 한쪽으로만 쌓인다.

`종가/시가` 로 고치자:

| | 1등 연수익 | 벤치마크를 이긴 조합 |
|---|---:|---:|

### 베타가 아니다 — 그런데도 통과하지 못한다

"그냥 시장을 레버리지한 것 아닌가"를 먼저 확인했다. 아니었다 —
베타가 **0.65~1.06** 으로 1 근처거나 아래인데 알파가 연 10~27% 나온다.

그래서 다중검정 문턱을 걸었다. 5,176개를 시험했으므로 Šidák 보정 후
필요한 |t| 는 **4.42** 다. 자기상관까지 보정한(Newey-West) 알파 t 는:

| 규칙 | 베타 | 연알파 | 알파 t (NW) | 통과 |
|---|---:|---:|---:|:--:|
| williams_oversold_turn+ribbon_up/60일 | 0.87 | 15.7% | 2.96 | ✗ |
| ema_pullback+near_range_low/60일 | 0.80 | 17.9% | 2.45 | ✗ |
| williams_oversold_turn_trend+volume_surge/10일 | 0.80 | 26.9% | 2.26 | ✗ |
| cup_with_handle+adx_strong/60일 | 0.92 | 14.3% | 2.21 | ✗ |

**상위 15개 중 0개 통과.** 최고가 2.96 인데 문턱이 4.42 다.

### 결정적 검정 — "이 방법으로 골랐다면 벌었을까"

문턱 이야기는 추상적이다. 실제로 해보면 된다. 과거 한 시점에 서서
그때까지의 데이터로 1등을 뽑고, **그 다음 구간에 그대로 쓴다**. 6번 반복.

| 폴드 | 뽑은 규칙 | 학습 연수익 | 검증 연수익 | 벤치마크 | 초과 |
|---|---|---:|---:|---:|---:|
| 1 | stoch_cross_up+volume_surge/10일 | 126.8% | +9.5% | +11.2% | −1.7% |
| 2 | williams_oversold_turn_trend+volume_surge/10일 | 66.1% | **−41.2%** | +0.3% | −41.5% |
| 3 | williams_oversold_turn_trend+volume_surge/60일 | 32.2% | +45.3% | +46.6% | −1.4% |
| 4 | williams_oversold_turn_trend+volume_surge/60일 | 34.2% | +0.8% | +6.5% | −5.6% |
| 5 | stoch_cross_up+ribbon_up/20일 | 37.3% | +15.4% | +16.5% | −1.1% |
| 6 | stoch_cross_up+ribbon_up/20일 | 35.5% | −7.4% | **+68.3%** | −75.6% |

**0승 6패. 부호검정 p=0.031** (폴드 6개에서 나올 수 있는 최소값이다).

학습 구간 평균 연 **55.3%** → 검증 구간 평균 연 **3.7%**.
같은 기간 아무것도 안 하고 전 종목을 들고 있으면 연 18.5% 였다.

### 그래서 뭐가 남았나

순위표 1등은 실력이 아니라 **줄 세우기의 부산물**이다. 5,176개를 세우면
1등은 반드시 나오고, 그 1등은 다음 구간에 평범해진다. 폴드 2와 6이 특히
아프다 — 뽑은 규칙이 시장이 오르는데 혼자 손실을 냈다.

이 구간(2015~2026)에서 실제로 돈이 된 것은 하나뿐이다:

```
유니버스 동일가중 매수후보유   연 18.52%   MDD −44.7%
KODEX 200 (실제 시장)         연 16.99%
```

둘의 차이 1.53%p 가 **생존편향**이다 — 오늘 시총 상위인 종목만 골라
과거를 봤기 때문에 생긴 공짜 수익이고, 실제로는 얻을 수 없다.

## 자산군에서 ETF 로 — 실행 계층에서 결론이 한 번 더 바뀐다

앞의 "6자산 동일가중"은 **자산군** 결론이다. 실제로 사는 것은 자산군이 아니라
종목 코드가 붙은 ETF 고, 그 순간 백테스트가 보지 못하는 세 가지가 붙는다.
`python -m tsignal portfolio --root data_asset` 로 재현된다.

### 1. 유동성 — 내가 고른 달러 ETF 가 틀렸다

평균이 아니라 **중앙값**을 쓴다 (테마가 붙은 며칠이 평균을 끌어올린다).

### 2. 환노출 — "금"은 하나가 아니다

금 ETF 두 개의 일간 상관은 0.7885 밖에 안 된다. 같은 금값을 따라가는데 왜?

```
(현물금 − 헤지금) 와 달러 의 상관        0.6003
현물금에서 달러 수익률을 뺀 뒤 헤지금과 상관  0.8808   ← 0.79 에서 올라감
누적:  현물금 2.859배   헤지금 2.162배   달러 1.365배
       현물금에서 환효과를 빼면  2.859 ÷ 1.365 = 2.094  ≈  헤지금 2.162
```

차이의 정체는 **환헤지 여부**다. 처음에 이걸 선물 롤 비용으로 적었는데
틀렸다 — 롤 비용이라면 달러와 상관이 생길 이유가 없다.

포트폴리오에 넣어보면 (공통기간 2021-12-15 ~ 2026-08-28, 4.7년):

| 구성 | 연수익 | 12개월 양수율 | 최악 12개월 | 궤양지수 | MDD |
|---|---:|---:|---:|---:|---:|
| ① 환헤지금 + 달러 (6자산) | 13.24% | 0.924 | −9.57% | 3.80 | −12.02% |
| ② **환노출금 + 달러 (6자산)** | 14.49% | **0.938** | **−8.50%** | **3.42** | −13.00% |
| ③ 환노출금, 달러 없음 (5자산) | 15.82% | 0.920 | −11.72% | 4.83 | −14.25% |
| ④ 환헤지금, 달러 없음 (5자산) | 14.25% | 0.911 | −13.05% | 5.54 | −15.71% |
| (참고) 한국주식 100% | 26.17% | 0.781 | −25.06% | 13.60 | −40.81% |

②가 네 지표 중 셋에서 가장 낫다. 다만 **4.7년은 결론을 내기에 짧다** —
411060 이 2021-12 상장이라 그 이상 늘릴 수가 없고, 하필 이 구간은 한국주식이
연 26% 오른 예외적 상승장이다. 앞의 7등분 구간 검증 같은 것을 할 표본이 없다.
"관측"이지 "검증"이 아니다.

### 3. 계좌 — 연금계좌가 유리한 건 맞는데, 이유가 다르다

일반계좌는 리밸런싱마다 실현이익에 15.4% 가 붙는다 (국내주식형 ETF 는
매매차익 비과세). 연금계좌는 운용 중 과세가 없다. 같은 코드로 세율만 바꿔
두 번 돌렸다 (9.7년, 6자산 동일가중):

| 계좌 | 연수익 | 1,000만원 → | 누적 납부세액 |
|---|---:|---:|---:|
| 연금계좌 (운용 중 비과세) | 10.72% | 26,768,000원 | 0% |
| 일반계좌 (리밸런싱마다 과세) | 10.28% | 25,758,000원 | 원금의 6.41% |

세금 드래그 **연 0.44%p**. 리밸런싱을 자주 할수록 커진다:
연 1회 0.34%p · 분기 0.44%p · 월 0.54%p.

복리로 벌어지는 금액 (분기 리밸런싱, 원금 1,000만원):

| 기간 | 연금계좌 | 일반계좌 | 차이 |
|---|---:|---:|---:|
| 10년 | 2,769만원 | 2,661만원 | 108만원 |
| 20년 | 7,668만원 | 7,081만원 | 587만원 |
| 30년 | 2억 1,233만원 | 1억 8,842만원 | 2,391만원 |

**중요한 것은 이 표가 아니다.** 여기 안 들어간 것이 훨씬 크다 —
연금계좌 납입액 900만원에 대한 **세액공제 13.2~16.5%** 는 매년
118~148만원을 돌려받는 것이고, 이건 운용 성과가 아니라 납입 시점의
환급이라 백테스트로 잴 대상이 아니다. 위 표의 10년치 차이(108만원)를
세액공제는 **첫 해에** 넘어선다.

반대편에는 인출 시 연금소득세 3.3~5.5%, 55세 이전 중도해지 시
기타소득세 16.5%, 그리고 IRP 의 위험자산 70% 한도가 있다.
6자산 동일가중은 주식이 33% 라 한도에는 여유가 있다.

과세 모형에서 일부러 뺀 것 (전부 일반계좌를 **유리하게** 만드는 방향이므로,
위 0.44%p 는 일반계좌 쪽 최선의 경우다): 손익통산·손실이월, 분배금 원천징수,
금융소득종합과세.

### 부수적으로 잡힌 버그 — 리밸런싱의 46%가 실행되지 않았다

이 작업 중 `static_mix` 에서 리밸런싱 시점을 `resample("QE").last().index`
로 잡고 있는 것을 발견했다. 그건 값을 모을 때 쓰는 **구간 라벨**(3/31, 6/30…)
이라 그 날이 휴장이면 어떤 봉과도 일치하지 않는다. KODEX 200 24년치에서
분기말 96번 중 **52번만** 거래일이었다 — 절반 가까운 리밸런싱이 조용히
건너뛰어지고 있었다. 실제 마지막 거래일을 쓰도록 고쳤고
(`_rebalance_marks`), 회귀 테스트를 붙였다.

6자산 동일가중의 결론은 바뀌지 않았다 (9.7년, 리밸런싱 19회 → 40회):

| | 연수익 | 12개월 양수율 | 최악 12개월 | 무저점 일수 | 궤양지수 | MDD |
|---|---:|---:|---:|---:|---:|---:|
| 6자산 동일가중 | 10.72% | **0.875** | **−9.54%** | **342일** | **2.85** | **−12.02%** |
| 한국주식 100% | 18.07% | 0.615 | −29.63% | 967일 | 14.96 | −40.81% |

## 수익 극대화는 왜 막히는가

"샤프가 가장 높은 포트폴리오를 만든 뒤 레버리지" — 이게 정석이다.
자산 6종(한국주식·나스닥·국고채3년/10년·금·달러, 2011-10~2026-08, 14.9년)으로
검증했다.

### 1. 레버리지 비용이 길을 막는다

주식 100% 와 **같은 위험**으로 맞췄을 때 손익분기 차입금리:

| 포트폴리오 | CAGR | 변동성 | 필요 레버리지 | 손익분기 금리 |
| --- | --- | --- | --- | --- |
| 주식40/채권60 | 7.18% | 9.7% | 2.32배 | **3.03%** |
| 주식35/채권40/금15/달러10 | 7.42% | 9.4% | 2.41배 | **3.72%** |
| 5자산 동일가중 | 5.85% | 6.3% | 3.58배 | **3.21%** |

한국 개인 신용융자 금리는 **5~9%** 다. 전부 손익분기 아래로 못 내려간다.

### 2. 레버리지 ETF도 막힌다 (KODEX 레버리지 16.5년 실측)

| | |
| --- | --- |
| 일간 추종 정확도 | 회귀 기울기 1.985, 상관 0.997 — **ETF 는 제 역할을 한다** |
| 기초자산 CAGR | 12.09% |
| 2배 기대 | 24.17% |
| **실제** | **15.28%** (연 **−8.9%p**) |
| MDD | −40.8% → **−68.4%** |

이론 끌림(σ²)이 5.03%p 이고 나머지는 보수와 조달비용이다. 네 구간 전부에서
2배에 못 미쳤다(−4.75 ~ −10.74%p). **위험은 2배 넘게 지고 수익은 1.26배를 얻는다.**

### 3. 레버리지 없이 최대 수익 — 사후 관찰일 뿐

| 자산/포트폴리오 | CAGR | 변동성 | 샤프 | MDD |
| --- | --- | --- | --- | --- |
| **나스닥 100%** | **20.62%** | 19.0% | 0.981 | −31.0% |
| 나스닥70/금15/달러10 | 15.99% | 13.6% | **1.025** | −21.6% |
| 한국50/나스닥50 | 17.39% | 17.7% | 0.868 | −29.1% |
| 한국주식 100% | 12.66% | 22.6% | 0.472 | −40.8% |

나스닥이 세 축 모두에서 한국주식을 이긴다. 다만 **이건 사후에 가장 좋았던 자산을
고른 것**이고, 2011~2026 은 미국 기술주의 역사적 강세장이었다.
장기 주식 샤프는 보통 0.3~0.5 인데 0.981 이 나왔다는 것 자체가 특수 구간의 신호다.
5등분 구간에서 나스닥의 샤프 우위는 4/5 (p=0.375) 로 유의하지 않다.

### 4. 분산의 샤프 개선도 표본을 늘리면 흔들린다

6자산 동일가중 vs 한국주식 100%:

| 등분 | 샤프 우위 | p | MDD 우위 | p |
| --- | --- | --- | --- | --- |
| 5등분 | 5/5 | 0.062 | — | — |
| **7등분** | **4/7** | **1.000** | **7/7** | **0.016** |

**구간을 늘리자 샤프 우위가 사라진다.** 남는 것은 낙폭 감소뿐이고,
그건 위험 비중을 줄이면 당연한 결과다.

### 결론

**수익을 극대화하는 검증된 방법은 찾지 못했다.** 레버리지 경로는 비용이 막고,
분산은 낙폭만 줄인다. 지난 15년 CAGR 을 최대화한 것은 나스닥 100%(20.6%)였지만
그건 발견이 아니라 사후 관찰이다.

## 유일하게 통과한 것 — 분산투자

가격에서 신호를 뽑는 시도가 전부 실패한 뒤, **예측이 전혀 없는** 쪽으로 갔다.
주식과 채권을 섞고 정기적으로 리밸런싱하는 것. 미래를 맞힐 필요가 없다.

KODEX 200 + KODEX 국고채3년, 2009-07 ~ 2026-08 (17.1년). **일간 상관 0.032.**

| 포트폴리오 | CAGR | 변동성 | 샤프 | MDD |
| --- | --- | --- | --- | --- |
| 주식 100% | 12.24% | 22.3% | 0.548 | −40.8% |
| 주식60/채권40 분기리밸 | 9.11% | 13.9% | **0.655** | **−25.8%** |
| 주식40/채권60 분기리밸 | 7.21% | 9.9% | **0.725** | **−17.8%** |
| 주식60/채권40 무리밸 | 9.80% | 16.8% | 0.584 | −37.0% |

**6등분한 모든 구간에서 이긴다.**

| 검증 | 결과 | 부호검정 p |
| --- | --- | --- |
| 60/40 샤프 우위 | **6/6** | **0.031** |
| 60/40 MDD 우위 | **6/6** | **0.031** |
| 리밸런싱 자체 기여 | 4/6 | 0.688 (분산 효과가 주된 것) |

레버리지로 위험을 주식 100% 수준에 맞춰도(차입 3% 가정) CAGR 12.4~12.8% 로
주식 100%(12.24%)를 넘는다. 레버리지 없이 보면 **수익의 75% 를 위험의 60% 로**
얻는다는 뜻이다.

### 이건 발견이 아니다

마코위츠 이후 70년 된 이야기이고 모든 교과서에 있다. 다만 이 프로젝트에서
**실제로 검증을 통과한 유일한 것**이다. 이유는 명확하다 — 예측을 하지 않기 때문이다.
상관이 낮은 자산을 섞으면 변동성이 수익보다 더 많이 줄어드는 것은
수학적 성질이지 시장에 대한 주장이 아니다.

금리 급등기(2021~2023, 채권 CAGR +0.20%, 상관 +0.28)에도 60/40 이 이겼다.

### 유일한 전제이자 위험

**주식-채권 상관이 낮게 유지되어야 한다.** 연도별 상관은 −0.36 ~ +0.44 사이를
오갔고, **2026년이 +0.44 로 표본 내 최고**다. 상관이 계속 오르면 분산 효과는 줄어든다.
`test_diversification_benefit_shrinks_as_correlation_rises` 가 이 성질을 고정한다.

## 그 밖에 시도한 것 — 전부 기각

개별 종목 신호가 전부 실패한 뒤 **추세추종**으로 옮겼다. "무엇이 오를지"가 아니라 "지금 위험을 질 때인가"만
판단하는, 훨씬 약한 주장이다.

KODEX 200 **24년치**(2002-10 ~ 2026-08, 2008 금융위기 포함)로 검증했다.
규칙은 전부 발표된 문헌 그대로다.

| 전략 | CAGR | 변동성 | 샤프 | MDD | 매매횟수 |
| --- | --- | --- | --- | --- | --- |
| **매수후보유** | **13.71%** | 23.88% | 0.574 | −52.7% | 1 |
| Faber 10개월 SMA | 10.69% | 19.29% | 0.551 | −40.8% | 45 |
| 200일 SMA | 9.77% | 18.10% | 0.540 | −40.8% | 191 |
| 절대모멘텀 12개월 | 9.61% | 19.38% | 0.496 | −40.8% | 37 |
| 변동성타겟 10%(밴드) | 6.63% | 10.92% | **0.607** | **−24.2%** | 116 |

**추세추종은 매수후보유를 이기지 못한다.** CAGR도 샤프도 낮다.

### 두 종류의 하락

| | 2008 (느린 약세장) | 2026 (5주 만에 −40%) |
| --- | --- | --- |
| 매수후보유 | −52.7% | −40.8% |
| 200일 SMA | **−18.2%** | −40.8% |
| 변동성타겟 | −22.3% | **−7.1%** |

추세 신호는 가격이 기준선을 뚫을 때까지 기다려야 한다. 강한 상승 뒤 급락에서는
기준선이 한참 아래라 대응이 늦다. 변동성 타겟팅은 방향을 예측하지 않고 변동성만
보므로 폭락 첫날부터 줄인다. **막는 하락의 종류가 다르다.**

### 변동성 타겟팅은 무엇을 주는가

24년을 6등분해 매수후보유와 비교하면:

| | 승패 | 부호검정 p |
| --- | --- | --- |
| 샤프 우위 | 4/6 | 0.688 — **유의하지 않음** |
| MDD 우위 | **6/6** | **0.031** — 유의함 |

그리고 2026년 폭락을 빼면 샤프는 오히려 **진다**(0.629 vs 0.675).
레버리지로 위험을 맞춰도(변동성 19%) CAGR 11.6%로 매수후보유 13.7%에 못 미친다.

**결론: 수익률을 높이는 방법이 아니다. 낙폭을 줄이는 방법이다.**
그리고 "위험 비중을 줄이면 낙폭이 준다"는 발견이라기보다 항등식에 가깝다.

목표변동성을 6%~20%로 바꿔도 샤프가 0.60~0.77로 평평하다 — 위험 수준은
**취향의 문제**이지 최적화 대상이 아니라는 뜻이다. 밴드(10%)를 넣으면
매매가 5,555회 → 116회로 줄고 성과는 오히려 조금 나아진다.

## 컵앤핸들 — 표본을 늘리자 무너졌다

지표·조합·팩터·수급이 전부 기각된 뒤, **차트 형태 패턴** 5종을 시험했다.
문헌 기준(오닐 CANSLIM 등)을 그대로 코드로 옮겼고 이 데이터로 튜닝하지 않았다.

199종목·5년에서는 컵앤핸들이 통과하는 것처럼 보였다 —
연환산 +15.9%, t=3.03, 4개 구간 전부 양수, BH-FDR 통과.

그래서 **표본을 368종목·11년으로 3.4배 늘렸다.** 진짜 효과라면 t가 √3배쯤
올라야 한다. 결과는 반대였다.

| 표본 | 이벤트 | 연환산 | t |
| --- | --- | --- | --- |
| 199종목 · 2021~2026 (원래) | 1,262 | +12.1% | 2.44 |
| 199종목 · 2015~2021 (기간 확대) | 899 | +8.9% | 1.08 |
| 368종목 · 2021~2026 (종목 확대) | 2,279 | +9.0% | 1.67 |
| **368종목 · 11년 (전체)** | **4,104** | **+8.4%** | **1.52** |

**기간을 넓혀도, 종목을 넓혀도 둘 다 약해진다.** 원래 결과는 2021~2026년
대형주 구간에 특수했던 것이다. 어떤 잣대(Šidák 3.07, BH-FDR)도 통과하지 못한다.

### 그래도 남는 것

방향은 일관되게 양수다. 11년을 6등분하면 5/6 구간이 양수이고
(+12.3 / +4.8 / +14.5 / −3.5 / +20.0 / +7.3%), 완화판 대조군은 2/6 뿐이다.
민감도에서 선행 상승 조건을 빼면 성과가 사라지는 구조도 그대로다.

즉 **"아무것도 아니다"와 "확실하다" 사이**에 있다. 이 데이터로는
우연과 구분되지 않는다는 것이 정확한 표현이다.

## 그 밖에 기각된 것들 (199종목 · 5년 일봉)

삼성전자·SK하이닉스 등 코스피 대형주 24종목, 2021-10 ~ 2026-08, 총 28,720봉.

**단일 신호: 전부 기각.** 27개 트리거 중 채택후보 0개, IS·OOS 부호가 일치하는
신호도 없음.

**필터 15개: 기각.** 12폴드 워크포워드에서 도움이 되는 필터도, 해로운

### 수급도 안 됐다

가격·거래량으로 안 되니 **투자자별 수급**을 붙였다. 네이버 금융에서 199종목
5년치 기관·외국인 순매매량을 받아 같은 파이프라인에 태웠다.

결과는 가격 팩터보다도 약하다. 스프레드 자체가 0.3% 미만이고, 용량-반응
단조성도 없다(ρ이 −0.42~+0.15로 방향이 잡히지 않음). 흥미로운 건 `inst_ratio`
(기관 순매수 비중)의 **부호가 음수**라는 것 — 기관이 산 종목이 오히려 덜 올랐다.
다만 유의하지 않으므로 그렇게 읽어서는 안 된다.

### 한때 "발견"이었다가 철회된 것

이 세션에서 두 번 헤드라인 결과가 나왔다가 둘 다 통계 결함으로 판명됐다.

1. **`volume_above_avg`** (24종목 단일 분할) → 12폴드 워크포워드에서 6/12로 붕괴
2. **`trend_down` 12/12 폴드, p=0.0005** → 기준선을 창 안 평균으로 잡은 인공물.
   횡단면 기준선으로 바꾸니 4/12, p=0.39

두 번째는 특히 위험했다. 다중검정 보정, 날짜 군집 보정, 12폴드 워크포워드를
**전부 통과한 상태**였는데도 틀렸다. 검증 관문을 여러 개 세워도 기준선 정의가
틀리면 소용이 없다. 합성 랜덤워크 대조군이 없었다면 못 잡았을 것이다.

전체 결과는 `reports/walkforward_1d.md`, `reports/factor_1d.md`,
`reports/universe_1d.md`, `reports/combination_1d.md` (직접 생성).

## 지금 상태와 다음 논의거리

**되는 것**: 유니버스 자동 구성(시총 상위 199종목) · 실데이터 수집(가격+수급) ·
지표 61종 · 트리거 41개 · 상태필터 15개 · **차트 형태 패턴** · 횡단면 팩터 분석 ·
**캘린더-타임 포트폴리오** · 12폴드 롤링 워크포워드 · 리포트 6종 · 테스트 155개.

**검증 장치 8종** (각각이 실제로 가짜 발견을 하나씩 잡아냈다):
미래참조 검사 · 다중검정 보정 · 날짜 군집 보정 · 횡단면 기준선 · 겹침 보정 ·
베타 분리 · 자기상관 보정(Newey-West) · 유니버스 전체 벤치마크.
모두 합성 랜덤워크 대조군으로 회귀 테스트돼 있다.

**아직 없는 것**: 분봉. 네이버 공개 엔드포인트는 일봉만 준다.

**정해야 할 것** — 이야기 나누고 진행하죠:

1. **분봉 조달** — 단타의 본 무대는 1/3/5분봉인데 아직 못 구했다.
   (a) 브라우저 헤더로 토스 뚫기, (b) 한국투자증권 Open API 어댑터,
   (c) 유료 벤더. 추천은 **(b)** — 재현 가능성이 데이터 출처에 걸려 있다.
2. **6자산 동일가중이 답이었다.** 궤양지수 7/7 구간 우위(p=0.016),
   12개월 양수율 62% → 89%. 나스닥 수익을 깎아도 유지된다.
   수익은 낮지만 꾸준하고, 예금의 1.8배다.
3. **분산투자의 위험조정 개선은 약하다.** 주식/채권 60/40 분기 리밸런싱이 6/6 구간에서
   샤프와 MDD 모두 주식 100% 를 이겼다(p=0.031). 예측이 없어서 통과했다.
   전제는 주식-채권 상관이 낮게 유지되는 것이고, 2026년 상관이 +0.44 로
   표본 내 최고라는 점은 주의해야 한다.
4. **가격·거래량 데이터는 여기까지다.** 지표 61종 → 트리거 39개 → 조합 2,440개
   → 팩터 14종 → 차트 패턴 11종을 전부 훑었고, 정직하게 검증하면 살아남는 것이 없다.
   컵앤핸들이 가장 근접했지만 표본을 늘리자 무너졌다.
5. **남은 축은 이벤트 데이터.** 공시, 실적 서프라이즈, 컨센서스 변화.
   공개 엔드포인트로 과거 시계열을 확보하기가 어렵다는 것이 문제다.
4. **생존 편향** — 유니버스를 199종목으로 넓혀도 상장폐지 종목이 없으면
   편향은 그대로다. 컵앤핸들 결과에도 이 편향이 남아 있다.
4. **숏 사이드** — 현재 롱 전용. 공매도 제약을 감안하면 실익이 있는지.
