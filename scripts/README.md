# 조회 스크립트

모두 저장소 루트에서 `.venv/bin/python scripts/<이름>.py` 로 돌린다.
신호 캐시(`parts16.pkl`)와 가격 캐시(`cache16.pkl`)가 스크래치패드에
있어야 한다 — 없으면 다시 만드는 데 20분쯤 걸린다.

| 스크립트 | 하는 일 |
|---|---|
| `watch.py` | **감시 목록.** 컵·핸들 모양이 완성돼 돌파선만 남은 종목. [A] 는 MFI 다리까지 장전된 ⑦ 후보, [B] 는 모양만 완성된 것. |
| `scan7.py` | 최근에 실제로 뜬 ⑦ 신호와 체결가·목표가·만기. |
| `cmp67.py` | ⑥ 과 ⑦ 의 연도별 성적과 최근 신호 공백. |
| `y2026.py` | ⑦ 규칙의 연도별 매매 내역 (청산까지 끝낸 값). |
| `refresh.py` | **일봉을 오늘까지 갱신한다.** 네이버 금융에서 인증 없이 받는다. 매매하는 날은 장 마감 후 먼저 이걸 돌린다. |
| `today.py` | **오늘의 매수 신호.** 최신 CSV 를 직접 읽어 마지막 며칠만 검사한다 — 검출기를 전부 다시 돌리지 않아 몇 초면 끝난다. `today.py 4` 처럼 검사할 거래일 수를 준다. ①·⑤·⑦ 을 따로 보여준다. |
| `five.py` | ⑤ 의 연도별 성적과 ① 과의 비교. |
| `capscale.py` | 시작 자금을 100만~5,000만으로 바꿔가며 1년 창 191개를 굴린다. 규칙마다 "담을 수 있는 그릇" 이 다르다는 것을 보여준다. |

## 매일 하는 일

    .venv/bin/python scripts/refresh.py     # 장 마감 후 일봉 갱신
    .venv/bin/python scripts/today.py 3     # 최근 3거래일 신호

신호가 뜬 다음 날 **시가**에 산다. 종가로 신호를 확정하므로 그날은 못 산다 —
이 하루는 모든 백테스트에 이미 들어가 있다.

## 규칙 ⑦ (굴림 창 191개에서 살아남은 것)

- **매수** — MFI 과매도 탈출 후 **20거래일 안에** 컵앤핸들 돌파. 돌파일
  종가로 확정하고 **다음 날 시가**에 산다.
- **금액** — 한 자리 33.3만원.
- **매도** — **+20% 도달** 또는 **60거래일 경과**, 먼저 오는 쪽. 손절 없음.
- **제외** — 20일 평균 거래대금 3억원 미만.

`watch.py` 는 검출기의 기하 조건을 그대로 쓰고 두 가지만 뺀다: 아직
돌파 안 했으니 `종가 > 손잡이 고점` 을 빼고 몇 % 남았는지를 재며,
돌파봉 거래량(50봉 평균의 1.4배)은 뚫는 날 정해지므로 미리 못 본다.
